## 무료로 퍼뜨리는 경로 (돈 안 드는 순서)

1. **검색 노출** — 아래 4개 검색엔진에 사이트 등록. 사이트맵(`sitemap.xml`)은 이미 만들어 둠.
   - Google Search Console (search.google.com/search-console) → URL 접두어 `https://fktu-nodong.vercel.app` → 소유권 확인 → Sitemaps에 `sitemap.xml` 제출
   - 네이버 서치어드바이저 (searchadvisor.naver.com) → 사이트 등록 → 소유권 확인 → 요청 > 사이트맵 제출
   - 다음 검색등록 (register.search.daum.net)
   - Bing 웹마스터 도구 (bing.com/webmasters)
   - 소유권 확인용 메타 태그 코드를 보내주면 사이트 head에 넣어 드림.
2. **기존 조직 채널** — 지역지부·업종 조직의 문자·단톡방·밴드·카페에 위 문구 배포. 가장 빠르고 비용 0.
3. **당사자 채널** — 산재·체불 상담을 받는 노동상담 창구, 지역 노동자 모임에 사이트 링크 전달.
4. **X·페이스북 계정 직접 운영** — 브라우저에서 로그인해 위 문구를 붙여 넣으면 됨(무료).
   - 자동 게시(예약 발행)는 X 개발자 앱 + 유료 플랜이 필요한 것으로 확인됨. 무료로 하려면 수동 게시.
5. **콘텐츠 확장** — 지금 있는 30편 지식 글 중 `임금체불`, `산업재해`, `해고` 3편을 각각 카페·블로그에 다시 올리면 검색 유입이 가장 큰 3개 키워드를 잡을 수 있음.

## 확인 필요 (사실관계)

- X 자동 게시 가능 여부·요금은 2026년 기준 확인 실패. 계정 로그인 후 X 개발자 포털에서 무료 등급의 쓰기 권한을 직접 확인해야 정확함.
- 네이버 카페 글쓰기 API는 카페 운영진 권한이 필요하고 무료 등급 제한이 있음.
